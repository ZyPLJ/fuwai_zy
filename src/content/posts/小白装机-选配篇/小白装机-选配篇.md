# 小白装机-选配篇

## 前言

出来工作挺久了，自己用的笔记本也是19年的产品，用起来有点卡。最主要的是带不动黑悟空了，那么也是有了想买台台式机的想法。

在选配阶段也是在抖音、B站、小红书上看了很多视频，自己做了很多功课。废话不多说，我先放出我的配置。

## 我的配置

主板：微星 B650M GAMING PLUS WIFI

CPU：AMD R5 7500F 盒装

显卡：七彩虹4060 UItra W

内存：金百达 银爵16*2 D5 6000 M-die C30 

散热：利民 240水冷

电源：长城G6 650W 金牌全模组

其他配件：3把棱镜6PRO 一正二反

屏幕：KTC Q24T09 2k 180HZ

机箱：玩嘉硕果海景公寓机箱

这里简单讲一下选择这套配置的原因，首先是主板，我觉得颜值还不错，然后有WIFI 6E非常重要，因为租房没网线，然后也能超频跑满这颗CPU，虽然网上说这款主板是水桶板，但以我这颗CPU来说完全不影响。

CPU选择的是AMD平台的7500F，一开始是准备选择Intel的12600KF的，不出意外就出意外了，涨价涨到1300了，最后选择了这款7500F，网友们称为网游神U。我对生产力和游戏其实没有特别的要求，流畅就行，所以AMD和Intel我都能接受。

显卡为了颜值选择了七彩虹的UItra，白色显卡，这里为什么不上4060Ti，主要是预算不够，4060可以畅玩3A了，够用，大不了调低一下游戏画质。

内存也是选择了金百达的M代颗粒C30时序的，新出的M代价格也便宜，如果上A代28时序超预算了。

散热和电源这可就随意选择了，选水冷是为了颜值！！！，电源也是选的长城电源有7年质保。

## 个人见解

这里详细讲解下我是如何选配的，首先得益于算法时代，当各大电商平台知道我想买台式机后，抖音、小红书、淘宝、拼多多、京东全在给我推电商主机。我也是在刷抖音的时候看到了胖哥装机，那段时间一下班就看胖哥的直播。他的直播类型就是粉丝连麦然后配主机。看了一段时间自然而然自己也懂了一点。当然我这套配置完完全全是刀把机，钱都花在了颜值上。

在有一定的基础后，也了解了当下装机热门的CPU，无可非议在1000左右价位就非AMD R5 7500和Intel 12600KF为主了。虽然7500F核心数比12600KF小，但7500F三缓多且超频成本低。可以将主频超至5.3。

那么简单讲一下这2颗U的区别

|             | AMD 7500F   | Intel 12600KF   |
| ----------- | ----------- | --------------- |
| 核显        | 无          | 无              |
| 核心数量    | 6           | 10              |
| 线程        | 12          | 16              |
| 频率范围    | 3.7~5.0 GHz | 3.6~4.9 GHz     |
| Max内存频率 | D5 5200     | D4 3200 D5 4800 |
| TDP功耗     | 65W         | 125W            |
| 二级缓存    | 6MB         | 9.5MB           |
| 三级缓存    | 32MB        | 20MB            |

7500F的优势就算功耗低三缓多，12600KF核心多。

网上有很多这2颗U的对比和评测，我这里就不多讲了。
